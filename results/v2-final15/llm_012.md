`b_blocks` is the one lever aimed at exactly that, and it has never been swept. B (= X, the WS stationary operand) is moved in as DIM-column tiles: at width 1 each row is 16 B against `dma_maxbytes = 64`, so every request carries a quarter of its allowed payload. At `b_blocks = 4` (= N/DIM = 64/16, the whole X row, and exactly the `dma_maxbytes` cap) one request replaces four, cutting X's ~2,048 resident-load requests to ~512 for identical bytes. DRAM traffic is unchanged — this is a request-*count* move, not a traffic move — so the 22 pJ/byte term stays put and any win lands on cycles.
